# Model Artifacts and Registry

Веса моделей хранятся локально. Текущие/потенциальные будущие версии, обучающие данные,
метрики валидации, базовые показатели дрейфа и правила продвижения описаны в
[`../../specs/Monitoring_Drift_Retraining.md`](../../specs/Monitoring_Drift_Retraining.md).

## Расположение

Все файлы весов должны находиться в:

```text
./src/models/
```

## Файлы моделей

| Filename                    | Назначение                                   |
|-----------------------------|----------------------------------------------|
| `car_detector.pt`           | Детекция автомобиля на изображении           |
| `license_plate_detector.pt` | Детекция номерного знака                     |
| `plate_ocr.pt`              | OCR: распознавание символов номерного знака  |
| `car_embedder.pt`           | Построение эмбеддинга изображения автомобиля |
